---

## 🗂️ **Archive Policy**

### **When to Archive**
- ✅ **Completed one-time tasks** (migration scripts, setup guides)
- ✅ **Superseded documentation** (replaced by newer versions)
- ✅ **Outdated plans** (no longer relevant to current implementation)
- ✅ **Duplicate content** (when multiple docs cover same topic)

### **When NOT to Archive**
- ❌ **Active implementation guides** (currently being used)
- ❌ **Reference documentation** (still needed for development)
- ❌ **Business strategy docs** (ongoing value)
- ❌ **Architecture documents** (foundational knowledge)

---

## 🔄 **Archive Management**

### **Archival Process**
1. Move outdated documents to `/docs/archive/`
2. Update this README with archive reason
3. Update master index in `/docs/README.md`
4. Remove any broken links from active documentation

### **Cleanup Schedule**
- **Monthly Review**: Check for outdated documents in active folders
- **Quarterly Cleanup**: Review archived docs for permanent deletion
- **Before Releases**: Clean up temporary and migration documents
